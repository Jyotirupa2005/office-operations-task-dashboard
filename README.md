# Office Operations & Task Management Dashboard

A portfolio project for analyzing routine office operations in a software-development environment.

### Covers
Client communication • Meeting coordination • Manual user testing • Screencast creation •
Office events • Management support • Documentation • Follow-ups • Pending work • Blockers

### Stack
Excel + Python/Pandas + MySQL + Power BI

### Important
The dataset is synthetic portfolio data. It is intentionally varied to look like normal
business operations, but it is not real company/employee/client data.

### Suggested Power BI pages
1. Management Overview
2. Task & Workload
3. Communication & Meetings
4. Issues & Delays
